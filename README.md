## 🚀 How to Host on GitHub Pages (Step-by-Step)

Because this website is built with zero build steps or heavy dependencies, hosting it on **GitHub Pages** is instant and free!

### Option A: Host under your primary domain (`https://KhushiV12.github.io`)

1. Go to [GitHub](https://github.com/) and click **New Repository**.
2. Name the repository exactly:
   ```text
   KhushiV12.github.io
   ```
   *(Make sure it is set to **Public**)*.
3. In your local terminal inside this folder (`d:\My\Portfolio`), run:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release for Khushi Vinchhi"
   git branch -M main
   git remote add origin https://github.com/KhushiV12/KhushiV12.github.io.git
   git push -u origin main
   ```
4. Within 1-2 minutes, your website will be live at:
   👉 **`https://KhushiV12.github.io`**

---

### Option B: Host under a project repository (`https://KhushiV12.github.io/portfolio`)

1. Create a public GitHub repository named `portfolio`.
2. Push your code:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/KhushiV12/portfolio.git
   git push -u origin main
   ```
3. On GitHub, go to your repository **Settings** → **Pages** (on the left sidebar).
4. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
5. Your live site will be ready at:
   👉 **`https://KhushiV12.github.io/portfolio`**
